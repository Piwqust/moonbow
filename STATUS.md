## 8. Тестирование и правила

- `tools\dev\launch.ps1 -DataDir <папка> -Fresh [-Library <папка>] [-Settings '{...}'] [-Exe ...] [файлы]`
  запускает изолированный экземпляр с громкостью 0 и печатает PID.
- **Тестовые экземпляры (`--automation`) невидимы:**
  - окна скрыты через DWM cloak;
  - кнопки на панели задач нет;
  - фокус не перехватывается;
  - нет трея, медиаклавиш, системных диалогов, Проводника и записи в реестр.

  Смотреть окно можно только через `tools\dev\capture.ps1`.
- `input.ps1` эмулирует клики, клавиши и текст, с `-Ctrl`/`-Shift`. `dump-tree.ps1` выводит дерево виджетов.
- Проверки кода:
  - `python tools/dev/check-icons.py`, `python tools/dev/check-settings.py`, `python qa/i18n_check.py`;
  - иконки: SVG в `design/icons`, затем `powershell -File tools/gen-icons.ps1`.
- Тестовые медиа: `bash qa/make-media.sh <короткий путь>`, большая медиатека — `qa/perf/biglib.ps1`.
- Если владелец запустил свой Lumen из `build\Lumen.exe`, файл занят. Тогда собирать с
  `LUMEN_OUT=%TEMP%\lumen-qa\build-main` и его процесс не трогать.

**Правила:**
- мышь и фокус пользователя не трогать;
- закрывать только свои PID;
- не открывать системные диалоги и не менять реестр;
- медиа пользователя не трогать;
- ничего не скачивать и не запускать из интернета;
- Figma bridge (`localhost:3055`) только на чтение;
- компьютер в сон не отправлять;
- сообщения коммитов писать в `.git\MSG` без BOM, коммитить `git commit -F`, заканчивать строкой Co-Authored-By;
- агентам: коммитить после каждого шага и держать тестовые файлы под уникальным префиксом (общие имена в `%TEMP%\lumen-qa` и scratchpad уже приводили к затиранию).
