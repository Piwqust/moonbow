## 1. Задача (что просил пользователь)

1. Реализовать дизайн из Figma «VLC Redesign» полностью, улучшить его и перевести в монохром
   («белый на графите»). Тёмная тема основная, светлая зеркальная.
2. Довести приложение до отполированного состояния с оптимизацией. Дальше пользователь даёт правки.
3. Вести git (работа в `main`, коммиты разрешены).
4. Под конец два раунда «жёстких новых пользователей»: субагенты тестируют и пишут правки,
   я их исправляю. **Сейчас идёт раунд 1** (см. раздел 4).

## 3. Инструменты для тестов

- Изолированный экземпляр:
  `build\Lumen.exe --new-instance --automation --data-dir <папка> [файл]`.
  `ui.json` с `{"onboarded":"1"}` пропускает онбординг.
- В `tools\dev\` (все берут `-ProcessId`):
  - `capture.ps1`: скриншот окна в фоне, включая слой DComp.
  - `input.ps1`: клики, колесо, drag, клавиши, текст в UTF-16 через PostMessage. `-Ctrl`/`-Shift` работают с `--automation`.
  - `dump-tree.ps1`: дерево виджетов с координатами.
- Тестовые медиа генерирует `bash qa/make-media.sh "$TEMP/lumen-qa/media"` (нужен ffmpeg; длинный
  путь скретчпада не подходит, нужен короткий). Медиа пользователя не трогать.
- Замер старта: `LUMEN_TRACE=1` пишет `%TEMP%\lumen-trace.txt`.

**Правила** (действуют и для субагентов):
- не двигать мышь пользователя и не забирать фокус;
- закрывать только свои PID, никогда `taskkill /IM Lumen.exe`;
- не открывать нативные диалоги и Проводник;
- не нажимать «Сделать плеером по умолчанию»;
- не менять системные настройки;
- не изменять, не переносить и не удалять медиафайлы пользователя;
- не менять файл Figma (bridge `localhost:3055` только на чтение).

Сообщения коммитов пишутся в `.git\MSG` без BOM, коммит через `git commit -F`. Каждое сообщение
заканчивается строкой `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

### Находки power: что исправлено и что осталось

Исправлено (коммит 5ba4772):
- **P01.** Досмотренный файл (последние 5% или ≥5 с до конца) больше не сохраняет позицию,
  в том числе при выходе (mpv сам писал её через `save-position-on-quit`). Проверено вживую.
- **P02, частично.** «Назад» по эпизодам работает, потому что прошлые серии больше не стартуют с конца.
- **P12.** Задержки звука и субтитров и петля A-B сбрасываются на следующем файле. Watch-later
  хранит только позицию и дорожки. `privacy.rememberPosition` управляет этими сохранениями.

Осталось (по порядку важности, детали и вероятные причины — в отчёте):

1. **P05, Major.** Клик по кнопке панели даёт ей фокус, и Space потом нажимает её вместо паузы.
   Кнопки не должны брать фокус от мыши (Host.cpp ~703, ~800).
2. **P04, Major.** Автоподгонка окна берёт размеры предыдущего файла. `fitPending_` сбрасывается,
   пока `videoW/H` ещё старые (App.cpp ~501): нужно ждать новые размеры после загрузки файла.
3. **P03, Major.** Несуществующий путь запускает случайный файл папки (`BuildFolderQueue`,
   App.cpp ~581). Нужна проверка существования и сообщение «Файл не найден».
4. **P06, Major.** `.m3u/.m3u8` из командной строки не открывается. Разбирать через `ReadM3u`
   (Playlists.cpp:71) в очередь.
5. **P11, Major.** Битые файлы: сейчас сырая строка mpv на 1,2 с и пустой плеер. Нужно постоянное
   сообщение в плеере с именем файла и кнопками «Следующий»/«Закрыть».
6. **P07, P08, P09, P10, P17, Major/Minor.** OSD для смены аудио и субтитров (имя дорожки), глав
   («Глава 2/3: …»), A-B (разные тосты и метки на seekbar), перемотки стрелками, «Конец списка».
7. **P02, остаток.** Двойное быстрое P: позиция ещё не обновилась после асинхронного seek
   (`App::Previous`).
8. **P13.** `audio.volumeStep` игнорируется (Actions.cpp ~306, захардкожено ±5).
9. **P14.** Тост скриншота показывает «Изображения\Lumen» даже при своей папке; показывать
   реальный путь и только после успеха.
10. **P15.** Оставшееся время обрезается («-00:01:…»), режим не запоминается. Убрать часы для
    файлов короче часа, сохранять выбор.
11. **P16.** Один открытый файл молча превращает папку в очередь и играет дальше. Определиться
    с `playback.whenFinished = stop`.
12. **P18.** В узком окне seekbar 148 px: сворачивать слайдер громкости в иконку.
13. **P19.** Нечитаемые файлы в «Недавно добавленных»: помечать или скрывать.
14. **P20.** Stop (S) уходит в медиатеку, а в MPC-HC Stop остаётся в плеере на 0:00.
15. **P21.** Внешняя дорожка показывается как «srt»: показывать имя файла и язык; «Нет» вынести наверх.
16. **P22.** Пик памяти на 4K ~1 ГБ private: проверить лишние поверхности и `hwdec`.
17. **P23–P26, Polish.**
    - Контраст пройденной части seekbar.
    - Иконки громкости в тосте (выкл./тихо/громко).
    - Единый заголовок: без расширения.
    - Пресеты клавиш MPC-HC/mpv; убрать R (запись) с одиночной клавиши.

### Известные пробелы из отчётов агентов-модулей

- Медиатека: только одиночное выделение; плейлисты, изменённые вне медиатеки, обновляются только
  при следующем изменении библиотеки (у сервиса плейлистов нет сигнала); нет тултипов для
  обрезанных имён.
- Панели плеера: нет аудиовизуализатора; волна на seekbar декоративная; светлая тема и high-DPI
  не проверены глазами.
- Настройки: у общего `ui::Dropdown` нет галочки у выбранного пункта; карточки выключенных эффектов
  не раскрываются; нет глобальных горячих клавиш.
- Диалоги: «Настроить плеер» не умеет двухрядную раскладку из макета; нет OpenSubtitles.
- Переводы: ключ «Remove» переводится по-разному (Убрать/Удалить), побеждает первый найденный.

## 5. Как продолжить

1. Исправить оставшиеся находки power (список выше). После каждого блока собрать
   (`cmd //c ".\build.bat"`), проверить в изолированном экземпляре и закоммитить.
2. Заморозить новую сборку: скопировать `build\Lumen.exe` и `build\libmpv-2.dll` в
   `%TEMP%\lumen-qa\build-r1\`, заменив старую, чтобы перезапущенные ревьюеры видели исправления.
   При необходимости заново сгенерировать медиа и положить бриф в `%TEMP%\lumen-qa\`.
3. Перезапустить ревьюеров **library**, **design** и **stability** по промптам из
   `qa/round1/PROMPTS.md`, в фоне, параллельно. power можно не повторять или дать ему проверить
   исправления.
4. Свести все отчёты в один список, исправить, закоммитить. Сохранить отчёты в `qa/round1/`.
5. **Раунд 2**: новая замороженная сборка `build-r2`, ревьюеры с теми же ролями (можно добавить
   «новичка без опыта»). Промпты с `round2`/`build-r2`, исправления.
6. Обновить README (горячие клавиши и возможности изменились), финальный коммит и отчёт пользователю.
