# Сайт Lumen

Статический сайт плеера на Astro. Идея и дизайн-система: [DESIGN.md](DESIGN.md).

```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # готовый сайт в dist/, его можно выложить на любой статический хостинг
```

- Весь текст лежит в `src/data/site.ts`. Значения с пометкой `placeholder` нужно заменить: адрес сайта
  (ещё и в `astro.config.mjs` и `public/robots.txt`), ссылку на скачивание и на исходный код.
- Скриншоты: `src/assets/shots/*.webp`, настоящие окна Lumen 1440×900. Чтобы заменить экран, положите WebP
  с тем же именем. Демо-медиа на них сделаны из фото Unsplash, авторы на странице «Скачать».
- Движение: `src/engine` (прокрутка, появления, переходы), `src/motion/home.ts` (живой таймкод и шкала вечера).
