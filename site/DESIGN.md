# Сайт Lumen: дизайн

## Бриф

- **Что:** Lumen, видео- и аудиоплеер для Windows 10/11 с медиатекой. C++20, Direct2D, libmpv, GPL-3.0.
- **Для кого:** люди, у которых свои файлы (фильмы, сериалы, музыка) и которым надоели тяжёлые или
  шумные плееры.
- **Задача сайта:** за 3 секунды объяснить, что это за плеер и чем он отличается, показать настоящие
  экраны, привести к скачиванию (или сборке из исходников).
- **Язык:** русский (интерфейс плеера по умолчанию русский). Английская версия: позже.
- **Допущения (placeholder):** адрес сайта `lumen-player.example`, ссылка на скачивание и репозиторий,
  версия «0.9». Демо-медиа на скриншотах сделаны из фото Unsplash (Picsum), исполнитель «Сава Ветров»
  и сериал «Тихий берег» выдуманы. Всё это помечено в `src/data/site.ts`.

## Система

### Палитра (из `design/DESIGN.md` плеера; монохром, цвет только у медиа)

| Роль | Hex | Откуда |
|---|---|---|
| ground | `#090909` | `bg.deep` плеера |
| ink | `#EAEAEA` | `text.primary` |
| muted | `#8B8B8B` | `text.tertiary` (AA на ground: 5.9:1) |
| line | `#262626` | `line` |
| accent | `#EDEDED` | `accent` «Белый» (бегунок, Play) |
| curtain | `#000000` | чёрный кадр до «проявления» |

Цвет на сайте есть только внутри скриншотов. Это и есть идея плеера: серый интерфейс, цветной фильм.

### Шрифты

- **Onest** (Google, OFL, кириллица родная): всё, кроме времени. Заголовки 300 с трекингом −0.03…−0.05em.
- **JetBrains Mono** 100–300: только время (таймкод, засечки шкалы, длительности). Моно здесь —
  это данные, не украшение.
- Inter (шрифт самого плеера) сознательно не взят: он виден на скриншотах, сайт не должен с ними сливаться.

### Сетка и ритм

12 колонок, gutter `clamp(16px, …, 40px)`. Три вертикали: кол. 1 (таймкод), кол. 6 (экраны),
кол. 9 (подписи). Ритм секций: hero во весь экран → липкая «шкала» (длинная) → плотный список
возможностей → воздух перед финалом.

### Форма

Радиус 8 px у окон-скриншотов (как у окна Windows 11), 999 px у кнопок-пилюль (как кнопка Play
в плеере), 0 у всего остального.

### Движение

- Ease: engine `ease` (expo/power3). Hover 0.3 с, проявление 0.2–0.6 с.
- **Проявление из чёрного:** `opacity 0 → 1` и `filter: brightness(0) → 1` на маленьких элементах;
  экраны меняются кроссфейдом через чёрный, никогда не два движения одновременно.
- **Hover, основная кнопка:** «перемотка» — заливка бежит слева направо, как пройденная часть
  seekbar (scaleX от левого края), текст инвертируется.
- **Hover, навигация:** под ссылкой рисуется тонкая полоса прогресса слева направо (как seekbar).
- **Ссылки в тексте:** подчёркивание в покое, на hover утолщается.
- **Idle:** таймкод идёт в реальном времени, пока страница открыта (как играющий фильм): младшие
  разряды тикают, даже если ничего не трогать. Под reduced motion стоит.
- **Переходы страниц:** «стоп-кадр»: страница гаснет в чёрный (как Стоп → 0:00), новая проявляется.
- Загрузчика нет: Lumen показывает окно с первым кадром, сайт тоже. Это решение концепции.

### Тест на шаблонность

- Был центрированный hero с большим скриншотом. Заменил на split frame с таймкодом: тот, кто
  получил бы похожий промпт, сделал бы «скриншот + три карточки».
- Были «три карточки преимуществ». Убраны: преимущества разложены по шкале времени.
- Тёмный сайт + один акцент — шаблон. Здесь акцента нет совсем, цвет даёт только медиа, и это
  сказано словами в секции «Монохром».
