Lumen,
глава за главой

Lumen: минималистичный видео- и аудиоплеер для Windows с медиатекой, на C++20, Direct2D и libmpv, в монохроме «белый на графите». Здесь всё, что с ним произошло за четыре дня, по раундам правок. Внизу экрана полоса перемотки, как в самом плеере: каждая засечка это глава. Листайте вниз, и вы перематываете назад, к первой сборке.

Файл открывается как видео

При запуске файла окно было пустым 0,2 с, потом всё приходило разом: яркая картинка вместе с панелями. Теперь рамка плеера есть с первого кадра окна, а картинка проявляется внутри неё.

2520.10.2026Windowsв main

Lumen как своя программа Windows

Медиа-карточка с обложкой, недавние файлы на панели задач, команды в Проводнике: Lumen встраивается туда, где Windows их ждёт.

  • Медиа-карточка Windows показывает обложку и позицию, а Play продолжает с места остановки.
  • Список последних файлов в меню значка на панели задач. Кнопки на миниатюре видны и на светлой панели задач.
  • В Проводнике «Воспроизвести в Lumen» и «Добавить в очередь Lumen». Они появятся после «Сделать плеером по умолчанию».
  • Ссылку из браузера можно перетащить в окно. У полей ввода есть меню «Вырезать, Копировать, Вставить».
  • Клавиши громкости по умолчанию снова меняют громкость Windows, старое поведение включается в настройках. Тема по умолчанию «Как в системе», старые настройки остаются тёмными.

Проверить руками: карточку, список и команды тестовые экземпляры не видят. Список в FIX-STATUS.md

2220.10.2026Текстыв main

Одно понятие, одно слово

Одно и то же называлось по-разному в меню, настройках и знакомстве. Теперь у каждого понятия одно слово, а пары сверяет check-language.py.

  • Очередь везде называется очередью, а не «Плейлистом» в меню плеера и в настройках.
  • Счётчики пишут существительное страницы: «3 альбома», «2 сериала», «8 песен» вместо «элементов».
  • Подсказки поиска звучат по-русски: «Поиск в истории» вместо «Поиск в «История»».
  • «Щелчок» вместо «клика», «Не удалось» для любой ошибки, «Убрать из истории», когда файл остаётся на диске.
  • Термины поясняются словами, а сам термин стоит в скобках: «Сглаживать градиенты (дебандинг)».

2120.10.2026Плеерв main

Быстрая панель: этот файл и все файлы

Под одним заголовком «Основные» лежали настройки, которые действуют только на играющий файл, и те, что меняют все следующие. Теперь это две отдельные группы.

  • Вкладка «Видео»: «Для этого файла» (отражение, поворот, масштаб, соотношение сторон, с пометкой, что они сбрасываются) и «Для всех файлов» (кроп, деинтерлейс, HDR, тональная компрессия, разрешение).
  • Под строкой наборов одна фраза объясняет, зачем они: вернуться к сохранённым значениям.
  • Меню плеера сгруппировано по задачам.
  • Карточка ошибки воспроизведения стала диалогом с выходом, и после ошибки одного файла плеер больше не остаётся мёртвым.
  • У внешних дорожек значок удаления вместо карандаша, у «Стопа» значок стопа.

Плейлисты: несколько сразу и отмена

Плейлист собирался только мышью и по одной песне, а удалённое пропадало без возврата. Теперь можно выделить много и передумать.

1620.10.2026Клавиатурав main

Всё доступно с клавиатуры

Панель управления пряталась вместе с фокусом, и вернуть её можно было только мышью. Теперь по Lumen можно пройти целиком без мыши.

  • «Назад» и «Вперёд» в медиатеке: Alt+стрелки и боковые кнопки мыши. Под открытым плеером они медиатеку не листают.

Экранный диктор видит Lumen

Для экранного диктора очередь, закладки, главы и дорожки были одной кнопкой, в имени которой все пункты подряд. Теперь диктор видит списки, выбранный пункт и изменения.

  • Диктор знает текущий раздел, страницу, тему, акцент и язык интерфейса.
  • Живой Narrator стоит проверить вам: тестовые экземпляры его не запускают.

0418.10.2026Производительностьв main

Скорость

Замеры на RTX 4080 и большой медиатеке. Упор на то, что видно сразу: первый кадр, первый скан и память.

  • Устройство Direct3D создаётся при старте процесса, а первые кадры рисует WARP, пока грузится драйвер видеокарты.
  • Кадры рисуются из WM_PAINT, поэтому ввод во время анимации обрабатывается сразу.
  • Сканирование идёт в 4 фоновых потока, кэш сохраняется по ходу. Жанр читается при скане и хранится в кэше.
  • Превью карточек, ушедших с экрана, отменяются; память под превью ограничена по байтам.
  • В простое медиатеки 0 % процессора.
