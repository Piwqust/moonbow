# Cognitive walkthrough 1: первый запуск → фильм из медиатеки → другие субтитры

**Персона:** Марина, 34, переходит с VLC, средний уровень, Lumen видит впервые, нетерпелива, работает мышью.
**Задача:** пройти знакомство, включить фильм из медиатеки, переключить субтитры на другой язык (рус/англ).
**Сборка:** `%TEMP%\lumen-qa\ux-build\Lumen.exe`, чистый профиль, знакомство включено, окно 1280×780.
**Фильм:** `Videos\Chaptered Demo (1080p).mkv` (eng с флагом default, rus).
**Скриншоты:** `%TEMP%\lumen-qa\uxw-first\*.png` (вне репозитория, номера ниже).
Оценки: ✅ ясно, ⚠️ трение, ❌ провал.

## Итог

**Успех с первой попытки у новичка: ~70 %.** По шагам: знакомство ~95 %, запуск фильма ~85 %, субтитры ~85 %.
Знакомство аккуратное, панель дорожек хорошая. Слабые места:
- переход «нашла фильм → он играет»;
- язык субтитров не следует выбору пользователя.

## Рекомендации

1. ▶ на карточке запускает видео с одного щелчка: проверять попадание в круг 48 px в `ItemGrid::OnClick`. Ожидаемо +10–15 п. п.
2. Тост «Субтитры: X» / «Аудио: X» при выборе в панели, тот же, что у клавиш.
3. Подсказки с клавишей: «Субтитры (V)».
4. Язык субтитров и озвучки по умолчанию брать из языка интерфейса Lumen или спросить на шаге языка.
5. Знакомство в 3 экрана: папка и язык → тема → готово.
6. «Видео» — сетка фильмов с превью, сериалы отдельной группой в правильном порядке.
