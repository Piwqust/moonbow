# Cognitive walkthrough 2: серия из Проводника → дорожки → продолжение → следующая серия

**Персона:** Денис, 27, смотрит сериалы в оригинале, много лет на MPC-HC, работает с клавиатуры.
**Задача:** открыть S01E01 из Проводника, включить другую аудиодорожку и субтитры, перемотать, закрыть.
Позже продолжить с того же места и перейти к S01E02 с тем же выбором дорожек.
**Сборка:** `%TEMP%\lumen-qa\ux-build\Lumen.exe`, русский интерфейс, 1280×780. Проводник имитирован путём к
файлу в аргументах запуска.
**Данные:** тестовый `media\Videos\Series S01` для задачи не годится: серии по 12 с, одна аудиодорожка, без
субтитров, а карточке следующей серии нужно больше 60 с (`PlayerOverlays.cpp:473`). Агент сделал копии
Chaptered Demo (90 с, eng/rus звук и субтитры) через `ffmpeg -c copy` в `%TEMP%\lumen-qa\uxw-series-media\Show S01\`.
Исходники не тронуты. Это отступление от правила 4 брифа: медиа лежат вне папки `media`.
**Скриншоты:** `%TEMP%\lumen-qa\uxw-series\*.png` (вне репозитория).

## Итог

**Успех с первой попытки: ~55 %.** По путям: клавиатура в стиле MPC-HC ~25 %, мышь ~75 %, «досмотрел до
конца → Смотреть сейчас» ~90 %. После закрытия и открытия следующей серии из Проводника дорожки
запоминаются в ~0 % случаев.
Основа крепкая:
- позиция и дорожки пишутся на диск, на главной есть «Продолжить просмотр»;
- `Enter` продолжает с точной секунды;
- `A`, `V` и стрелки показывают понятные сообщения;
- карточка следующей серии переносит языки.

Ломаются привычки MPC-HC (`S`, PgDn, Esc), а следующая серия доступна только через карточку в последние
секунды.

## Точки провала (после сверки с кодом)

| Приоритет | Находка | Причина |
|---|---|---|
| P1 | `S` = «Стоп» и сбрасывает позицию на 0:00. В MPC-HC это субтитры, в VLC «Стоп». Хуже всего, что в приложении две таблицы клавиш, и они расходятся: `src/app/Actions.cpp:36` даёт `S` → Stop, а `src/core/SettingsSchema.cpp:2449`/`:2485` пишет, что «S переключает субтитры». Знакомство показывает «Сменить субтитры — V» | Две таблицы клавиш |
| P1 | `N`/PgDn/⏭ отвечают «Конец списка», хотя карточка уже нашла следующую серию | `playback.folderAsPlaylist=false` (`SettingsSchema.cpp:1151`). Поиск серии (`PlayerOverlays.cpp:453`) с `Action::Next` не связан |
| P1 | Выбор языков переносится на следующую серию только внутри одного запуска | `CarryLanguages()` хранит его в памяти (`PlayerOverlays.cpp:528`) |
| P1 | Кружок ▶ на карточке «Продолжить просмотр» не запускает видео | Тот же `ItemGrid::OnClick`, что в сценарии 1 |
| P2 | Esc с открытой очередью уводит из плеера, а с открытой панелью «Аудио» только закрывает её | Непоследовательно |
| P2 | Без сообщений проходят продолжение с места, перенос дорожек и выбор из меню. Номера серии нигде нет, в заголовке тег title контейнера | |
| P3 | Нет «Аудио 2/2». Пробел и `Enter` на главной не продолжают последнее. Полоса прогресса на светлой миниатюре не видна. «Осталось» не обновляется. `Enter` не нажимает кнопку карточки | |

## Сравнение с MPC-HC и VLC

| Ожидание | MPC-HC / VLC | Lumen |
|---|---|---|
| Звук | A / B | ✅ A |
| Субтитры | S / V | ✅ V, ❌ S = Стоп |
| Следующий файл папки | PgDn / N | ❌ «Конец списка» (по умолчанию папка не очередь, это решение E2 из ESCAPES) |
| Esc | выход из полного экрана | ⚠️ выход в медиатеку |
| Меню по правому щелчку | да | ✅ |
| Память позиции и дорожек | опция | ✅ по умолчанию |

## Рекомендации

1. Одна таблица клавиш. Решить, чем будет `S`: «Субтитры» (MPC) или «Стоп» (VLC). В любом случае «Стоп»
   не должен стирать точку продолжения.
2. `N`/PgDn/⏭ при пустой очереди запускают найденную следующую серию. Если запускать нечего, кнопка
   приглушена. Это не противоречит решению E2 (одно видео не катится дальше само): серию запускает человек.
3. Запоминать языки для сериала (папка или название) в `file-settings.json`.
4. Сообщения «Продолжаем с 0:40», «S01E02 · Звук и субтитры: Русский», «Субтитры: Русский» после выбора в меню.
5. S01E02 в заголовке окна.
6. В тестовые медиа добавить сериал длиннее 60 с с двумя аудиодорожками и двумя дорожками субтитров.
