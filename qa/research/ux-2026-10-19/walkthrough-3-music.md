# Cognitive walkthrough 3: альбом → текст песни → «играть следующим» → сохранить плейлист

**Персона:** Оля, 22, пользуется Spotify. Терпения к десктопным конвенциям мало, работает мышью и правым щелчком.
**Задача:** включить альбом из медиатеки, видеть текст песни, поставить песню другого исполнителя
следующей, сохранить то, что играет, как плейлист.
**Сборка:** `%TEMP%\lumen-qa\ux-build\Lumen.exe`, медиатека `%TEMP%\lumen-qa\media`, 1280×780, тёмная тема.
Текст песни проверялся во втором экземпляре на `ux-worst\Music\Covers with lyrics`, потому что в `media` ни у
одной песни нет текста.
**Скриншоты:** `%TEMP%\lumen-qa\uxw-music\*.png` (вне репозитория).

## Итог

**Успех с первой попытки: вся задача ~0 % на тестовых песнях без текста, без пункта про текст ~35–45 %.**
Ядро как в Spotify на месте: страница альбома, «Воспроизвести следующим», очередь, плейлист из очереди.
Беда в том, что каждое действие лежит не там, где его ищут, а про отсутствие текста приложение молчит.

Правки после сверки с кодом (оценки агента смягчены):
- **Проглоченный щелчок.** Щелчок мимо панели только закрывает её. Так сделано специально, как в меню
  Windows (`src/ui/Host.cpp:855`): щелчок мимо меню не должен ставить видео на паузу. Для панели очереди и
  кнопок панели управления это спорно, поэтому P2.
- **Текст песни.** В тестовых медиа текстов нет, и ~0 % — следствие этого. Настоящая проблема: нет входа и
  нет состояния «текста нет», поэтому P1.

Пояснения:
- **Шаг 4.** Плитка «Альбомы» открылась одиночным щелчком, а альбом уровнем ниже требует двойного. Правило
  меняется в пределах двух экранов.
- **Шаг 6.** Окно уходит в полноэкранную обложку: страницы медиатеки и «Назад» нет. Обратный путь скрыт за
  безымянной иконкой «Боковая панель». Компактная медиатека рядом с плеером (16) уже очень похожа на Spotify.
- **Шаг 7.** В баре кнопки аудиодорожек, субтитров, настроек и очереди, кнопки «Текст» нет. Правый щелчок по
  обложке ничего не делает. «Субтитры» у песни показывают «Нет дорожек» и вкладку «Видео». Поиск LRCLIB
  выключен по умолчанию (`privacy.fetchLyrics`, это решение о приватности) и находится только поиском по
  настройкам. Если `.lrc` есть, текст показывается сам и сворачивается в строку при открытой очереди (34, 35).
- **Шаг 13.** Правый щелчок по треку очереди даёт «Воспроизвести / Выше / Ниже / Убрать». Правый щелчок по
  пустому месту ничего не делает. Действия «Сохранить очередь» в коде нет. Есть только галочка «Добавить
  текущую очередь» в диалоге нового плейлиста (`src/app/dialogs/Dialogs.cpp:1041`).
- **Шаги 14–16.** Почти весь диалог занимает зона «Перетащите файлы…». Галочка очереди мелкая, внизу и
  выключена. Если её пропустить, получится пустой плейлист.

## Рекомендации

1. Кнопка «Текст» в баре музыки. Если текста нет, она показывает карточку «Нет текста → Найти в интернете
   (LRCLIB) / Добавить .lrc». На первой песне без текста предложить включить LRCLIB: это одно явное
   согласие, приватность не страдает.
2. «Сохранить как плейлист» в шапке очереди и в правом щелчке по её пустому месту. В диалоге «Новый
   плейлист» при непустой очереди галочку включать по умолчанию и ставить над зоной файлов.
3. Одиночный щелчок открывает альбом, исполнителя и плейлист, как уже открывает категории.
4. Запуск музыки из медиатеки не уводит со страницы: мини-панель внизу или плеер с раскрытой медиатекой.
5. Щелчок мимо панели (не меню) закрывает её и нажимает то, по чему щёлкнули. Исключение — щелчок по видео:
   он только закрывает панель.
6. Для аудио убрать вкладку «Видео» в панели дорожек. Тост «„Песня 2“ будет следующей · Отменить».
