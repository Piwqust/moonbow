# Замеры производительности

Все скрипты запускают только фоновые экземпляры (`--automation`, невидимые) через
`tools\dev\launch.ps1` и закрывают лишь свои PID. По умолчанию берётся `build\Moonbow.exe`, другой
exe задаётся через `-Exe`. Тестовые медиа: `bash qa/make-media.sh` (в `%TEMP%\moonbow-qa\media`).

| Скрипт | Что меряет |
|---|---|
| `perf.ps1 [-Tag x] [-Runs 3]` | Старт (метки `MOONBOW_TRACE`: окно, mpv, файл), память и CPU в медиатеке, 1080p при воспроизведении и на паузе, 4K, время закрытия |
| `libopen.ps1 [-Extra "--opt=..."]` | Простой медиатеки и задержка от `loadfile` до старта воспроизведения по логу mpv |
| `mpvopt.ps1 -Extra "--opt=..."` | Один файл с доп. опциями mpv: CPU, память, строки лога про hwdec и VO |
| `biglib.ps1` | Создаёт медиатеку из 3500 жёстких ссылок в `%TEMP%\moonbow-qa\big` (без лишнего места на диске) |
| `stress.ps1` | Медиатека 3500 файлов: время скана, память, статистика кадров при прокрутке, наведении и поиске |
| `scan.ps1 [-NoThumbs]` | Время и CPU первого сканирования большой медиатеки |
| `thumbs.ps1` | Быстрая прокрутка папки из 400 видео (`%TEMP%\moonbow-qa\flat`) и скриншоты: успевают ли превью |
| `threadcpu.ps1 -ProcessId N` | Потоки процесса по CPU с модулем, где поток стартовал (кто грузит процессор) |
| `stlib.ps1` | Общий помощник: поиск окна, колесо и движение мыши через PostMessage |

**Статистика кадров.** При `MOONBOW_TRACE=1` раз в секунду в `%TEMP%\moonbow-trace.txt` пишется строка:
`frames N  layout avg/max  paint avg/max  present avg/max` (мс).

**Результаты 18.10.2026** (RTX 4080, 2560×1440 @ 144 Гц):
- окно ~40 мс от старта процесса (было ~60);
- mpv готов ~60 мс (было ~80);
- первый кадр из медиатеки ~100 мс;
- кадр UI: раскладка < 0,1 мс, отрисовка ~0,7 мс;
- простой медиатеки: 0–0,3% CPU, ~90 МБ private;
- 1080p: 2–8% одного ядра;
- первый скан 3500 файлов: 16–19 с (было ~60 с), тёплый старт с кэшем — скан ~0,1 с.
