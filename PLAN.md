# Lumen — план реализации

Минималистичный видеоплеер для Windows: C++20, Win32, Direct2D/DirectWrite, DirectComposition, libmpv.
Цель: запускается и открывает файлы быстрее MPC-HC, выглядит чисто и современно, в духе MPC-HC без перегруза.

---

## 1. Цели и не-цели

**Цели**
- Окно видно меньше чем за 100 мс после запуска (ориентир, проверяем замером).
- Первый кадр не медленнее MPC-HC на том же файле.
- Один компактный интерфейс: заголовок, видео, панель управления. Ничего лишнего.
- Всё управляется с клавиатуры и мышью, как в MPC-HC.
- Обычный `.exe` без установщика и без зависимостей, кроме `libmpv-2.dll` рядом.

**Не-цели первой версии**
- Медиатека, стриминг, конвертация, эквалайзер, визуализации (всё это есть в VLC-референсе, но противоречит минимализму).
- Win7/8. Поддерживаем только Windows 10 1903+ и 11.
- Свой декодер или рендер: этим занимается libmpv.

## 2. Дизайн

### 2.1 Что взято из референса (Figma «VLC Redesign»)
- Тёмная графитовая палитра, оранжевый акцент.
- Нижняя панель одной строкой: `prev · PLAY · next · 00:02:10 · [seekbar] · 00:25:40 · громкость · audio · subs · playlist · fullscreen`.
- Кнопка Play — залитый оранжевый прямоугольник со скруглением, остальные кнопки — тонкие серые иконки.
- Seekbar: тёмная дорожка, пройденная часть — приглушённый оранжевый, бегунок — яркая оранжевая «таблетка».
- Заголовок окна: имя файла по центру, системные кнопки справа.

### 2.2 Что убираем (минимализм под MPC-HC)
- Боковое меню медиатеки, вкладки, обложки, онбординг.
- Лишние иконки в заголовке (кроме имени файла и кнопок окна).
- Громкость как в MPC-HC: треугольный «клин», но в цвете акцента, без зелёного градиента.
- Окно настроек в первой версии не делаем, хватает mpv.conf.

### 2.3 Токены
| Токен | Значение | Где |
|---|---|---|
| `bg` | `#0F0F0F` | фон окна без видео |
| `chrome` | `#171717` | заголовок и панель управления |
| `chromeOverlay` | `#171717` @ 92% | панель поверх видео в полноэкранном режиме |
| `line` | `#262626` | разделители |
| `hover` | `#FFFFFF` @ 8% | подложка кнопки при наведении |
| `press` | `#FFFFFF` @ 14% | нажатие |
| `text` | `#E8E8E8` | основной текст и иконки при наведении |
| `textDim` | `#8F8F8F` | время, иконки в покое |
| `accent` | `#F28C28` | Play, бегунок, громкость, активные элементы |
| `accentDim` | `#F28C28` @ 32% | пройденная часть seekbar |
| `track` | `#2B2B2B` | дорожка seekbar и громкости |
| `danger` | `#C42B1C` | кнопка «закрыть» при наведении (как в Windows) |

Типографика: `Segoe UI Variable Text` (fallback `Segoe UI`), 12 px для времени и меню, 12 px semibold для заголовка. Цифры времени — tabular (`DWRITE_FONT_FEATURE_TAG_TABULAR_FIGURES`), чтобы не прыгали.
Иконки: шрифт `Segoe Fluent Icons` (Win11), fallback `Segoe MDL2 Assets` (Win10). Это векторные иконки, они чёткие на любом DPI и не требуют ассетов.

### 2.4 Размеры (в DIP, умножаются на DPI-масштаб)
- Заголовок: 32. Кнопки окна: 46 × 32.
- Панель управления: 48. Кнопки: 32 × 32, Play: 40 × 28, скругление 6.
- Seekbar: зона клика 20, дорожка 4 (6 при наведении), бегунок 4 × 14, скругление 2.
- Громкость: клин 56 × 14.
- Отступы панели: 12 по бокам, промежуток между кнопками 4.

### 2.5 Состояния и поведение
- **Пустое состояние:** по центру надпись «Перетащите файл или нажмите Ctrl+O» и кнопка «Открыть файл».
- **Оконный режим:** заголовок и панель всегда видны, видео между ними (как в MPC-HC).
- **Полноэкранный режим:** видео на весь экран, панель поверх видео, появляется при движении мыши, скрывается через 2 с вместе с курсором; заголовок скрыт.
- **Наведение на seekbar:** подсказка со временем над курсором.
- **Тосты:** короткие сообщения сверху слева («Громкость 70%», «Субтитры: Русский»), гаснут через 1.2 с.
- **Меню дорожек:** по клику на audio/subs открывается небольшой список над кнопкой, отрисованный нашим же UI (не системное меню).
- **Анимации:** только opacity у панели и тостов (150 мс ease-out). Без «прыгающих» эффектов.

## 3. Архитектура

```
Lumen.exe
├── App (Win32): главное окно, своя рамка, ввод, DPI, single instance
│   ├── VideoHost — дочернее HWND (disabled), в него рисует mpv
│   └── Overlay — DirectComposition target (topmost) поверх всего окна
│        └── composition swapchain (BGRA, premultiplied alpha) ← Direct2D рисует весь UI
├── Player: обёртка над libmpv (динамическая загрузка DLL, события, свойства)
├── Renderer: D3D11 + DXGI + DComp + D2D + DWrite
└── Ui: виджеты (заголовок, панель, seekbar, громкость, меню, тосты), hit-test
```

### 3.1 Почему так
- **Видео через `wid`.** mpv сам управляет своим D3D11 swapchain, vsync и HDR — это самая отлаженная часть mpv. Нам не нужно повторять тайминг кадров.
- **UI через DirectComposition `topmost`.** По документации Microsoft такой визуал выводится поверх дочерних окон. Значит, панель можно рисовать прямо поверх видео mpv без отдельных popup-окон и без мерцания.
- **Ввод.** `VideoHost` отключён (`EnableWindow(FALSE)`), поэтому клики по видео уходят главному окну. Плюс mpv запускается с `input-cursor=no` и `input-vo-keyboard=no`. Весь ввод обрабатываем мы.
- **libmpv грузится динамически** (`LoadLibrary` + `GetProcAddress`). Нет зависимости от import-библиотек MinGW, окно показывается раньше, чем грузится тяжёлая DLL.

### 3.2 Поток событий
1. `wWinMain` → DPI awareness → проверка single instance (mutex + `WM_COPYDATA` в уже открытое окно).
2. Создание окна и Overlay, первый кадр UI (пустое состояние) → `ShowWindow`. Окно уже на экране.
3. Фоновый поток: `LoadLibrary("libmpv-2.dll")` → `mpv_create` → опции → `mpv_initialize` → `PostMessage(WM_APP_MPV_READY)`.
4. В UI-потоке: подписка на свойства (`mpv_observe_property`), `mpv_set_wakeup_callback` → `PostMessage(WM_APP_MPV_WAKEUP)` → цикл `mpv_wait_event(0)`.
5. Если до готовности mpv пришёл файл (из командной строки или drag&drop), он ставится в очередь и открывается сразу после `READY`.

### 3.3 Опции mpv
```
wid=<VideoHost>            vo=gpu-next          gpu-api=d3d11
hwdec=auto-safe            keep-open=yes        idle=yes
osc=no                     osd-level=0          input-default-bindings=no
input-vo-keyboard=no       input-cursor=no      cursor-autohide=no
load-scripts=no            ytdl=no              terminal=no
config=yes + config-dir=%APPDATA%\Lumen      (пользовательский mpv.conf, необязательный)
save-position-on-quit=yes  watch-later-dir=%APPDATA%\Lumen\watch_later
```

### 3.4 Отрисовка UI
- Перерисовка только по событию (изменение состояния, наведение, таймер анимации). Без постоянного цикла 60 FPS.
- `time-pos` приходит часто, поэтому перерисовка от него не чаще 20 раз в секунду (и только если изменилась секунда или пиксель бегунка).
- Swapchain пересоздаётся по `WM_SIZE` через `ResizeBuffers`.
- Все размеры в DIP, масштаб из `GetDpiForWindow`, реакция на `WM_DPICHANGED`.

### 3.5 Своя рамка окна
- `WM_NCCALCSIZE` убирает системный заголовок, но оставляет рамку ресайза.
- `WM_NCHITTEST`: края → ресайз, заголовок → `HTCAPTION`, кнопка «развернуть» → `HTMAXBUTTON` (иначе в Win11 не работает меню Snap Layouts).
- Тёмная рамка и скругление Win11: `DWMWA_USE_IMMERSIVE_DARK_MODE`, `DWMWA_WINDOW_CORNER_PREFERENCE`.

## 4. Управление

| Действие | Мышь | Клавиши |
|---|---|---|
| Открыть файл | кнопка в пустом состоянии, drag&drop | `Ctrl+O` |
| Пауза | клик по видео, кнопка Play | `Space` |
| Перемотка | клик/drag по seekbar | `←/→` 5 с, `Ctrl+←/→` 30 с |
| Кадр вперёд/назад | — | `.` / `,` |
| Громкость | колесо, клин громкости | `↑/↓` ±5 |
| Без звука | клик по иконке динамика | `M` |
| Полный экран | двойной клик по видео, кнопка | `F`, `Enter`; `Esc` — выход |
| Пред./след. файл в папке | кнопки prev/next | `PageUp/PageDown` |
| Аудио / субтитры | кнопки с меню | `A` / `S` — переключить по кругу |
| Скорость | — | `[` / `]` ±0.1, `Backspace` — сброс |
| Скриншот | — | `Ctrl+S` |
| Закрыть | — | `Ctrl+W` — закрыть файл, `Alt+F4` |

### Результаты проверки (17.10.2026, Windows 11, монитор 2560×1440 @ 100%)
- Окно на экране через ~50 мс после старта процесса (~25 мс из них — загрузка до `wWinMain`).
- Интерфейс Direct2D через ~230 мс (ждёт загрузку драйвера GPU, ~150 мс), первый кадр видео ~300 мс.
- Проверено вживую: воспроизведение, клик по видео = пауза, пробел, полноэкранный режим и автоскрытие, Esc, перемотка кликом, подсказка времени, меню аудиодорожек, тост громкости, второй запуск передаёт файл в открытое окно, закрытие за ~70 мс с сохранением позиции.
- Не проверено: DPI 150%/перенос между мониторами, Snap Layouts на кнопке «развернуть», субтитры (не было файла с ними), Windows 10.
- Холодный старт MPC-HC не замерялся: он был открыт у пользователя.

### Этап 4. Продукт — *следующие сессии*
- Окно настроек (минимальное): язык субтитров/аудио по умолчанию, hwdec, папка скриншотов.
- Ассоциации файлов (регистрация в «Приложения по умолчанию»).
- SystemMediaTransportControls (медиаклавиши, плашка Windows).
- Кнопки в превью таскбара (`ITaskbarList3`).
- Плейлист-панель справа.
- Иконка приложения, установщик (Inno Setup) или portable zip.
- Дампы падений (`MiniDumpWriteDump`).

### Этап 5. Полировка и скорость — *следующие сессии*
- Замеры запуска через WPR/WPA: время до `ShowWindow`, до `mpv_initialize`, до первого кадра.
- Превью кадра при наведении на seekbar (второй экземпляр mpv, как thumbfast).
- Урезанная сборка libmpv (меньше DLL — быстрее загрузка).
- Опциональный переход на render API D3D11 (mpv 0.42+), если понадобится blur поверх видео.
- Доступность: минимальный провайдер UI Automation.

## 7. Риски

| Риск | Что делаем |
|---|---|
| Клики уходят в окно mpv, а не к нам | `VideoHost` отключён, `input-cursor=no`; при проблеме — прозрачный для ввода слой или render API |
| Мерцание при ресайзе | DComp-слой не зависит от `WM_PAINT`; фон окна рисуем сами (`WM_ERASEBKGND` → 1) |
| На Win10 нет `Segoe Fluent Icons` | fallback на `Segoe MDL2 Assets`, коды иконок те же |
| `libmpv-2.dll` не найдена | понятное сообщение в пустом состоянии и в MessageBox |
| Лицензия | сборки libmpv от shinchiro под GPL → Lumen распространяется под GPL-3.0-or-later |

## 8. Критерии готовности MVP
1. `build.bat` собирает `build\Lumen.exe` без ошибок и предупреждений уровня /W4 в нашем коде.
2. `Lumen.exe video.mkv` открывает окно, начинает воспроизведение, работает пауза, перемотка, громкость, полный экран.
3. Панель рисуется поверх видео в полноэкранном режиме и скрывается сама.
4. Второй запуск с файлом открывает его в уже открытом окне.
5. Размер окна и DPI корректны на мониторе 100% и 150%.
