# Lumen — скины

Скин — это JSON-файл, который переопределяет токены оформления из [DESIGN.md](DESIGN.md): цвета тёмной и
светлой темы, акцент, радиусы скруглений и прозрачность плавающей панели управления. По умолчанию
включён монохромный бренд Lumen; скин меняет только те токены, которые в нём записаны.

Где выбрать: **Настройки → Интерфейс → Скин**. Там четыре встроенных скина с миниатюрами и пункт
«Свой файл…». Скин применяется сразу во всех окнах: главном, настройках, мини-плеере и диалогах.
Свой файл Lumen перечитывает сам, как только файл сохранён, поэтому скин можно править вживую.

Настройки:

| Ключ | Значение |
|---|---|
| `interface.skin` | встроенный скин: `lumen` (по умолчанию), `oled`, `contrast`, `sepia` |
| `interface.customSkin` | `true` — использовать свой файл вместо встроенного |
| `interface.skinFile` | путь к своему файлу `.json` |

Из теста или скрипта: `tools\dev\command.ps1 -ProcessId <pid> -Command "set interface.skinFile C:\path\my.json"`,
затем `set interface.customSkin true`.

## Формат

```json
{
  "lumenSkin": 1,
  "name": {"en": "Ocean", "ru": "Океан"},
  "mode": "any",
  "colors": {"accent": "#4FA3FF"},
  "dark":  {"bg.base": "#0B1320", "bg.panel": "#111C2E", "text.secondary": "#9DB0C8"},
  "light": {"bg.base": "#F2F6FB"},
  "radius": {"control": 6, "card": 10},
  "controlBar": {"opacity": 0.9}
}
```

| Ключ | Что делает |
|---|---|
| `lumenSkin` | версия формата, сейчас `1` |
| `name` | строка или `{"en": ..., "ru": ...}`; пока используется только в журнале |
| `mode` | `"any"` (по умолчанию) — скин следует теме из настроек; `"dark"` или `"light"` — у скина одна тема, и она включается всегда |
| `colors` | токены для обеих тем |
| `dark`, `light` | токены для одной темы; перекрывают `colors` |
| `radius` | радиусы: `small` (2), `control` (4), `card` (6), `popup` (12), `window` (14), от 0 до 24 DIP |
| `controlBar.opacity` | непрозрачность плавающей панели управления, от 0.5 до 1. Без этого ключа панель непрозрачна (правило раунда 5) |
| `_…`, `$…` | комментарии, пропускаются молча |

**Цвета:** `#RGB`, `#RRGGBB` или `#RRGGBBAA`. Прозрачность разрешена только у `bg.hover`, `bg.press`,
`scrim` и `shadow`. У остальных токенов альфа отбрасывается с предупреждением, чтобы панели не стали
прозрачными случайно.

**Токены:** `bg.deep`, `bg.base`, `bg.raised`, `bg.panel`, `bg.chrome`, `bg.card`, `bg.selected`,
`bg.menu`, `bg.hover`, `bg.press`, `line.subtle`, `line`, `line.strong`, `text.primary`,
`text.secondary`, `text.tertiary`, `text.disabled`, `accent`, `accent.mid`, `accent.dim`, `accent.faint`,
`on.accent`, `scrim`, `shadow`, `danger`. Значения по умолчанию указаны в DESIGN.md, раздел 1.

Если скин задаёт `accent`, он заменяет тон акцента из настроек. Тогда `accent.mid`, `accent.dim`,
`accent.faint` и `on.accent` выводятся из акцента и `bg.base` по тем же формулам, что у бренда, если скин
не задаёт их сам. Фон под видео не меняется: mpv всегда рисует чёрный.

**Радиусы** заменяются по значению: в скруглении 4 DIP встаёт значение `control` и так далее. Скругления
другой величины (таблетки, круги, бегунки) остаются как есть.

**Шрифты** скин пока не меняет. Метрики интерфейса подобраны под Inter, и другой шрифт обрезал бы
подписи. Ключ `font` пропускается с предупреждением.

## Ошибки и предупреждения

- Неизвестные ключи и токены пропускаются с предупреждением.
- Плохое значение (не цвет, число вне диапазона) пропускается: этот токен остаётся как в Lumen,
  остальные применяются.
- Если файл не читается или это не JSON-объект, показывается Lumen.
- Для своего файла Lumen пишет `skin.log` в папку данных: предупреждения и итог проверки контраста.
  Под списком скинов в настройках выводится число замечаний, а сами строки — в подсказке.

## Проверка контраста

Для каждой темы, в которой работает скин:

- `text.primary` и `text.secondary` на всех фонах (`bg.base`, `bg.deep`, `bg.raised`, `bg.panel`,
  `bg.chrome`, `bg.card`, `bg.selected`, `bg.menu`) должны давать не меньше **4,5:1**;
- `text.tertiary` на `bg.base` и `bg.panel`, `accent` на `bg.base`, `bg.deep` и `bg.chrome`, `on.accent`
  на `accent` — не меньше **3:1**: это значки, подписи и элементы управления;
- `text.disabled` не проверяется: WCAG не требует контраста от недоступных элементов.

Если пара не проходит, в настройках появляется предупреждение со списком пар в подсказке и кнопка
«Сбросить», которая возвращает Lumen. Все встроенные скины проходят проверку со всеми тонами акцента:
это проверяет тест `builtin_skins` в `tests/core_tests.cpp`.

## Встроенные скины

Встроенные скины лежат в `res/skins/*.json` и вшиты в exe через `res/app.rc`. Их удобно брать как
образец.

| id | Название | Что меняет |
|---|---|---|
| `lumen` | Lumen | ничего: бренд из DESIGN.md |
| `oled` | Чёрный OLED | только тёмная тема; страница, заголовок и панель управления `#000`, панели `#0E0E0E`–`#1C1C1C` |
| `contrast` | Высокий контраст | ярче текст и линии, жёлтый (тёмная тема) или синий (светлая) акцент |
| `sepia` | Сепия | тёплые тона в обеих темах, скругления мягче (5 / 8 / 14 / 16) |

## Как устроено

- `src/core/Skin.*`: бренд-палитра, разбор файла, вывод производных токенов и проверка контраста. Код
  без окон, его проверяют тесты.
- `src/ui/Theme.*`: превращает разобранный скин в `Palette`, отображает радиусы (`Theme::Radius`, его
  вызывает `Painter`) и хранит прозрачность панели.
- `src/app/Skins.*`: читает настройки, загружает встроенный скин или файл и перерисовывает все окна.
  Для своего файла запускает поток с `FindFirstChangeNotification` на папку файла. Изменения
  собираются 150 мс, и файл перечитывается, только если у него изменились время записи или размер. Со
  встроенным скином нет ни потока, ни таймера, ни выделений памяти; Lumen по умолчанию даже не
  разбирает JSON.
